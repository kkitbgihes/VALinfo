# 🟪VALinfo - Simple VALORANT tracker🟪

Open-source VALORANT tracker with live match statistics, player analysis and match predictions.
VALinfo is a desktop application for VALORANT that provides live information about your current match, analyzes players and predicts match outcomes.

## Features

### Live Match

- Player statistics
- Agents and ranks
- Peak rank
- K/D, HS%, ADR and ACS
- Win rate and streaks
- Player level
- Party detection
- Country detection

### Match Prediction

- Win probability
- Expected score
- Overtime probability
- Score distribution
- Player performance predictions
- Explanation of factors affecting the prediction

### Player Analysis

- Player strength
- Recent form
- Best and worst statistics
- Threat rating
- Smurf probability
- Play style
- Historical performance

### Post-Match Analysis

- Full match scoreboard
- Player duels
- Economy statistics
- Round-by-round timeline
